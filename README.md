# Tetrıs Oyunu

Bu, Python ve Pygame kullanılarak yapılmış güzel bir Tetrıs oyunudur.

## Kurulum

Oyunu çalıştırmak ıçın öncelıkle Python ve `pygame` kütüphanesının yüklü olması gerekır.

1. **Gereklı kütüphanelerı yükleyın:**

   ```bash
   pip install -r requirements.txt
   ```

2. **Oyunu başlatın:**

   ```bash
   python tetris.py
   ```

## Kontroller

- **SOL OK:** Sola hareket ettırır.
- **SAĞ OK:** Sağa hareket ettırır.
- **AŞAĞI OK:** Daha hızlı düşmesını sağlar.
- **YUKARI OK:** Şeklı döndürür.

## Özellıkler

- Neon renk paletı ve modern görünüm.
- Yavaş başlangıç hızı (kullanıcı tercıhıne göre).
- Türkçe karakter desteğı (noktasız 'ı' kullanımı).
- Skor sıstemı ve sıradakı şekıl gösterımı.
